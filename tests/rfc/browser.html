RFC browser leg (manual — not gated)

A browser cannot open raw sockets or pick ALPN, so it is truth only for what it can speak: fetch semantics and WebSocket framing. Start the Bend servers first (see the ports below), open this file, and compare the log with the OK/DONE lines.

  1. H1: serve tests/rfc/h1_oracle.js server 19881 or the Bend H1 plain server on 19881, then press Fetch.
  2. WS: serve tests/rfc/ws_oracle.js server 19884 or the Bend WS plain server on 19884, then press WebSocket.
